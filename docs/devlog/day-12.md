# Day 12 — Cross-Encoder Reranking

## Goal
Add a Cross-Encoder after RRF to improve the final ordering of retrieved evidence.

## Architecture
The new pipeline correctly integrates the reranker as an advanced ordering step:

```
BM25 Top-20
+
Qdrant Embedding Top-20
↓
RRF Top-10
↓
Cross-Encoder Top-5
↓
Reasoning
↓
Human Review
```

## Why Cross-Encoder?
Embedding retrieval produces independent representations of the query and the documents. This is highly efficient for fast candidate generation across thousands of chunks but limits the model's ability to interpret deep linguistic interactions between the two. 
A Cross-Encoder jointly evaluates the `(question, passage)` pair simultaneously. This allows precise, attention-driven relevance scoring, capturing semantic subtleties that independent vectors miss. Because Cross-Encoders are computationally expensive, we strictly run them only on the Top-10 candidates generated by RRF.

## Model
The system uses the `BAAI/bge-reranker-large` model instantiated via the `sentence-transformers.CrossEncoder` class. It evaluates raw query-passage pairs and outputs robust relevance scores.

## Implementation
1. **RRF candidate generation:** We retrieve a broad but relevant set of candidates from both sparse (BM25) and dense (Qdrant) domains.
2. **Question/Passage Pairs:** The query and the `excerpt` from each RRF candidate are grouped into tuples.
3. **Reranker Scoring:** We pass the pairs through `bge-reranker-large` and append the float output to the candidate as `reranker_score`.
4. **Top-5 Selection:** Candidates are sorted by `reranker_score` descending, taking the top 5.
5. **Metadata Preservation:** The entire payload (`chunk_id`, `workspace_id`, `document_id`, `title`, `version`, `excerpt`, and `rrf_score`) survives the reranking process unharmed.

## Tests
- **Direct**: Ranked the explicit exact answer `#1`. 
- **Paraphrased**: Successfully promoted "Data in transit is protected using TLS" to rank `#1` (0.999 score) for the query about traveling data, fixing previous RRF ranking ambiguities.
- **Ambiguous**: "What is your retention policy?" preserved retention candidates but correctly deferred to `AMBIGUOUS` behavior for human clarification.
- **Conflicting**: "Are backups retained for 30 days or 90 days?" securely retained *both* `SEC-003` (30 days) and `SEC-005` (90 days) inside the Top-5, exposing the contradiction correctly as `CONFLICTING_EVIDENCE`.
- **Unanswerable**: Remains `INSUFFICIENT_EVIDENCE` without hallucinating or surfacing false positives.
- **Workspace Isolation**: Maintained complete tenant filtering prior to the reranker; impossible to leak cross-tenant evidence.

## Limitations
- Cross-Encoder improves ranking, not factual truth.
- It does not replace human review.
- It only reranks retrieved candidates.
- Q16–Q25 were not used for tuning or evaluating this implementation.
